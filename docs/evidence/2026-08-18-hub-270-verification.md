## Closing the issue

`gh api repos/libre-ai/libre-ai --jq '{archived: .archived}'` returns
`{"archived": true}`. GitHub rejects write operations — including closing an
issue — against an archived repository at the API level; this is not a
judgment call, it is enforced by GitHub itself. The issue is therefore
**not closable** and is documented here instead, per the arbitration's own
anticipation of this outcome. It remains open on the hub, cross-referenced
by this document.

This is a verification pass, not a remediation. Findings 1, 3 and 4 are open
